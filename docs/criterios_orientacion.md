# Criterios experimentales de orientación

La versión 2 usa una regla interna de demostración. No equivale a los baremos ni a la calificación de la Batería oficial.

- Frecuencia: 0 a 3 puntos.
- Duración: 0 a 3 puntos.
- Impacto: 0 a 2 puntos.
- 0 a 1: Orientación general.
- 2 a 4: Seguimiento preventivo.
- 5 a 8: Contacto humano recomendado.

Estos criterios deben ser revisados por profesionales antes de cualquier piloto real.
